# 📝 Journal & Notes App

A simple and elegant Notes App built with Flutter, designed to help users create, organize, edit, and manage their personal notes.

## ✨ Features

* 📝 Create and save notes
* ✏️ Edit existing notes
* 🗑️ Delete notes
* 📌 Pin important notes
* 🔍 Search through notes
* 💾 Store notes locally using Hive
* 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

* Flutter
* Dart
* Hive & Hive Flutter
* Flutter Bloc (Cubit)
* Material Design 3

## 🚀 Getting Started

### Prerequisites

* Flutter SDK
* Dart SDK
* Android Studio or VS Code

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Sondos-maher/Notes-App.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Notes-App
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the app:

   ```bash
   flutter run
   ```
